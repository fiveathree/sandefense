# 長坂坡字陣 sandefense

三國文字合成守塔網頁遊戲。抽字落格、同字同級升階、兩字成詞召喚武將或計策，與電腦守將同守二十波曹軍，比誰保得住阿斗。

## 玩法
- **抽字**：花糧隨機得一字，落在米字格上自動攻擊。
- **疊字升階**：同字同級相疊升一階（最高五階）。
- **兩字成詞**：如 趙＋雲、關＋羽、火＋攻、槍＋兵，召喚武將／計策／兵陣，各有技能。
- **羈絆**：桃園結義、五虎上將、長坂坡、三顧茅廬、赤壁、鳳儀亭、草船借箭。
- **對戰**：每斬 15 敵引一名精兵攻向對手；守滿 20 波，阿斗血多者勝。
