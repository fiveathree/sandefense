# 長坂坡字陣 sandefense

三國文字合成守塔網頁遊戲。抽字落格、同字升階、兩字或三字成詞召喚魏蜀吳名將，抽卡收集武將與兵器，與電腦守將比守阿斗。

## 玩法
- **包與抽字**：開局 9 包，每抽用 3 包，一抽五字；斬敵、每波開始、任務都會得包。
- **軍營**：抽到的字先入戰場下方軍營（開局 5 格，完成任務最多 8 格），再拖上米字格；場上的字可拖回軍營。
- **連字**：字在格上由左至右或由上至下相連成名即召武將，如「趙」「雲」相鄰即成趙雲。
- **疊字升階**：同字同階相疊升一階（最高五階）。
- **疊字**：同字同階相疊升階；疊在能成詞的字上亦會合成，三字名可排成一行或先疊殘詞。
- **稀有度**：武將分 R（紅框）、SR（紫框）、SSR（金框）。
- **抽將**：用元寶抽武將和兵器；重複武將升星；專武（如趙雲配涯角槍）加成最多。
- **陣容**：五員武將上陣，戰場只會抽到陣容武將的名字。
- **羈絆**：桃園結義、五虎上將、魏武揮鞭、江東雙璧等十五種。
- **戰場**：長坂坡、赤壁、虎牢關、官渡、夷陵、黃巾，每局輪換，各有特性。
- **對戰**：每斬 15 敵引一名精兵攻向對手；守滿 15 波，阿斗血多者勝。
